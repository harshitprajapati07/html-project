# Frontend Web Development Projects

A collection of web development projects built while learning and practicing HTML, CSS, JavaScript, and Node.js. This repository documents my progress in web development through hands-on projects.

## 🚀 Projects

### 1. TinDog — Dog Dating Landing Page
A responsive landing page inspired by a dating app for dogs.

- **Technologies:** HTML, CSS, Bootstrap
- **Key concepts:** Responsive layouts, navigation, pricing cards, and reusable UI components
- **Project folder:** [`11.3 TinDog Project`](./11.3%20TinDog%20Project/)

### 2. Mondrian Art — CSS Grid Layout
A recreation of a geometric artwork using CSS.

- **Technologies:** HTML, CSS
- **Key concepts:** CSS Grid, positioning, spacing, and layout composition
- **Project folder:** [`mondrian Project`](./mondrian%20Project/)

### 3. Password Protected Secret Page — Express.js
A simple web application that allows users to access a secret page by entering the correct password.

- **Technologies:** Node.js, Express.js, Body-Parser, HTML
- **Key concepts:** Express middleware, GET and POST requests, handling form data, and serving HTML files
- **Project folder:** [`Password Protected Secret Page`](./)

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder you want to explore.
3. For frontend projects, open the `index.html` file in your browser.
4. For the Express.js project, open the project folder in your terminal.
5. Install the required dependencies:

   ```bash
   npm install
   ```

6. Start the server:

   ```bash
   node solution.js
   ```

7. Open `http://localhost:3000` in your browser.
